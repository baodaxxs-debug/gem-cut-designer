# 宝石智能琢型设计系统

面向宝石琢型设计与课堂演示的浏览器应用。支持参数化刻面、对称与自由设计、滑动切割、材料折射率、BVH 光线追踪、原石包容分析，以及 ASC、DXF、GCUT 项目和切割步骤表导出。

当前版本为 Prototype 6.25，内置圆明亮式、烟花切、方形、梨形、三角形，以及圆形、椭圆、榄尖、垫形、长垫形、祖母绿、长方阶梯、雷迪恩、阿斯切和公主方等参数化入口。快捷切割工具已直接停靠在模型主界面：电脑端位于模型右侧，手机端位于模型下方，均不会覆盖宝石；进退、角度、单面/整层联动和 0.1 微调统一在这里完成，侧栏不再重复出现同一组滑块与按钮。CPU 光学分析使用 BVH 加速的真实三角面求交、斯涅尔折射、全反射、非偏振菲涅尔能量分配与 Beer–Lambert 体吸收。固定光学评价协议使用正面、12°和24°共九个方向，以及430–680 nm九波段采样；各波长折射率由材料d线折射率和F–C色散值拟合Cauchy曲线，并报告多角度一致性、回光标准差、回光极差与光谱回光极差，作为不同方案的可重复横向对比条件。电脑端 GPU 效果图使用五波段 CIE D65 合成、逐波段材料吸收和 64 次 HDR 渐进累积，参数变化后由用户点击开始渲染；材料预设目前属于可替换的工程近似光谱，不冒充单颗宝石的实测曲线。该协议属于软件内部研究方法，不是第三方机构的正式切工分级，也不替代实测光谱。代表光线可以叠加到三维主视图，逐次列出进入、全反射和菲涅尔分光事件，便于教学演示和论文验证。材料面板会随宝石自动显示等轴、三方、六方、四方或斜方晶系，以及各向同性、单轴或双轴光性；双轴计算目前明确使用平均折射率与双折射差近似。系统还支持真实布尔凹切、自由路径、体色分区、双折射晶轴显示、多视角光学推荐及完整项目保存。

## 本地运行

```bash
npm install
npm run dev
```

## 检查与构建

```bash
npm test
npm run build
```

## 在线发布

推送到 `main` 或 `master` 分支后，`.github/workflows/deploy-pages.yml` 会测试、构建并发布 `dist` 到 GitHub Pages。

本程序用于设计辅助与教学演示。正式切磨前仍需结合材料、原石、设备精度和实物缺陷复核。
