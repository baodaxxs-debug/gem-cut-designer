# 宝石智能琢型设计系统

面向宝石琢型设计与课堂演示的浏览器应用。支持参数化刻面、对称与自由设计、滑动切割、材料折射率、BVH 光线追踪、原石包容分析，以及 ASC、DXF、GCUT 项目和切割步骤表导出。

当前版本为 Prototype 6.16，内置圆明亮式、烟花切、方形、梨形、三角形，以及圆形、椭圆、榄尖、垫形、长垫形、祖母绿、长方阶梯、雷迪恩、阿斯切和公主方等参数化入口。快捷切割工具已直接停靠在模型主界面：电脑端位于模型右侧，手机端位于模型下方，均不会覆盖宝石；进退、角度、单面/整层联动和 0.1 微调可在观察模型时直接操作，并可一键折叠。模型选择继续以黄色主选面与编号、青色整层联动、蓝色相邻面及白色悬停轮廓区分。系统还支持真实布尔凹切、自由路径、体色分区、双折射晶轴显示、多视角光学推荐及完整项目保存。

## 本地运行

```bash
npm install
npm run dev
```

## 检查与构建

```bash
npm test
npm run build
```

## 在线发布

推送到 `main` 或 `master` 分支后，`.github/workflows/deploy-pages.yml` 会测试、构建并发布 `dist` 到 GitHub Pages。

本程序用于设计辅助与教学演示。正式切磨前仍需结合材料、原石、设备精度和实物缺陷复核。
