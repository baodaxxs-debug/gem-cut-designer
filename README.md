# 宝石智能琢型设计系统

面向宝石琢型设计与课堂演示的浏览器应用。支持参数化刻面、对称与自由设计、滑动切割、材料折射率、BVH 光线追踪、原石包容分析，以及 ASC、DXF、GCUT 项目和切割步骤表导出。

当前版本为 Prototype 6.5，包含圆明亮式、8 射线烟花切、樱花切和多种参数化外形。除常规刻面与棱边倒角外，还支持 V 形刀和圆头/球刀的真实布尔凹切、单边或整层联动、自由手绘连续刀具路径、实时预览、撤销恢复及完整项目保存。

## 本地运行

```bash
npm install
npm run dev
```

## 检查与构建

```bash
npm test
npm run build
```

## 在线发布

推送到 `main` 或 `master` 分支后，`.github/workflows/deploy-pages.yml` 会测试、构建并发布 `dist` 到 GitHub Pages。

本程序用于设计辅助与教学演示。正式切磨前仍需结合材料、原石、设备精度和实物缺陷复核。
